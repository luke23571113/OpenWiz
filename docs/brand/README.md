# OpenWiz logo

| File | Use |
| --- | --- |
| `openwiz-lockup-light.svg` | Mark and wordmark, dark text, for light backgrounds |
| `openwiz-lockup-dark.svg` | Mark and wordmark, white text, for dark backgrounds |
| `openwiz-mark.svg` | The mark in colour (ultramarine `#2B2BFF` with a white face) |
| `openwiz-mark-mono-black.svg` | One-colour mark for light backgrounds; the face is a cut-out |
| `openwiz-mark-mono-white.svg` | One-colour mark for dark backgrounds; the face is a cut-out |

The lockups have transparent backgrounds. The wordmark is converted to outlines, so the files contain no text and no font: they render the same everywhere, and no font file ships with them.
