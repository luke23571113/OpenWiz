pull request's base, `9d86900`: 514 tests, one row each, in the form of
`tools/test-value/README.md`, under cleanup wave #1141's rule (DL4): a test
stays only for a **user-visible behaviour**, a **contract another repository
relies on**, or a **safety gate** (privacy, security, data loss, money,
release). `tests/service/` files run as `openwiz-tests:service` (the `t2_*`
files) or as `openwiz-service` targets that `crates/service/Cargo.toml` points
here; `tests/loops/l6_executor.rs` runs as `openwiz-service:l6-switches`.

`install_engine_record_factory.rs`) compile into crate unit tests instead
([README.md](README.md)).

  they share the parent's keep reason.
