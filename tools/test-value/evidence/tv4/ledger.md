# TV4 (#806): the fleet group's ledger

Every test of the `fleet` target (`tests/fleet/`, run as `cargo test -p
openwiz-tests --test fleet`) at this pull request's base, `f95a553`: 294
tests, one row each, in the form of `tools/test-value/README.md`. Two more
rows are sub-proofs a wrapper test ran, which this group cut. A wrapper
(`…_preserve_…_cases`) is one `#[test]` that runs several named proofs
(#1259); its row covers them all.

- **Rows:** kept 275, moved 5, deleted 11, merged 5. Without the two
  sub-proofs (one deleted, one merged): 294 `#[test]`s, of which 275 stay,
  5 move to their crate's own `tests/` and 14 go.
- **ER6's tests:** 79 rows (72 in `b5_tick.rs`, `b5_edges.rs` and
  `b5_public.rs`, and the 7 of `pre_effect.rs` and `pre_effect_input.rs`)
  run the executing `fleet tick` or `--expect-plan`. ER1's map
  (`contracts/engine-retirement.v1.md`, section 7) gives them to ER6
  (#800), which deletes them and names their keepers. This group leaves
  the three `b5_*` files and the two `pre_effect*` files unchanged (ruling
  1 in the pull request), and rows them as kept for now.
- **Catches** for a kept test is the behaviour it asserts, read from its
  body: a change that breaks it fails the test.

## Why each cut

- `tests/fleet/a3_commands.rs::the_program_sends_each_command_to_its_own_files_run`: source mirroring: it grepped `crates/cli/src/main.rs` for each dispatch arm. The keeper runs the release `openwiz fleets`; `a5_agents_cli.rs::cli_agents_complete_answers_place_both_builders` runs the release `openwiz fleet`. A miswired arm fails both.
- `tests/fleet/a3_fake_gh.rs::a_scenario_extends_another_and_its_own_responses_come_first`: tests the fake only. The keeper's `checks-fail` scenario extends `complete`, overrides one answer and asserts everything else is unchanged.
- `tests/fleet/a3_fake_gh.rs::a_hanging_answer_writes_its_pid_and_never_answers`: tests the fake only. A fake that answered instead of hanging fails the keeper's `timed_out` assertion.
- `tests/fleet/a3_fake_gh.rs::started_by_name_through_path_it_shares_a_directory_with_the_fake_room_cli`: tests the fakes' directory only. The keeper runs the release `openwiz` with that `PATH` and asserts the exact `gh` call log and no `room-cli` call.
- `tests/fleet/a3_fake_gh.rs::with_no_scenario_it_answers_nothing`: tests the fake only; `FakeGh::new` always writes a scenario. The keeper proves the fake answers only what its scenario answers.
- `tests/fleet/a3_seams.rs::the_github_adapter_is_a_workspace_crate_beside_the_cloudroom_one`: compiler re-check: a crate outside the workspace can't be imported, so the keeper (and every test that imports `openwiz_adapter_github`) fails to build.
- `tests/fleet/a3_seams.rs::the_cli_depends_on_the_github_adapter_so_a4_and_a5_need_not_add_it`: compiler re-check: `crates/cli/src/fleets.rs` imports the adapter, so without the dependency the release `openwiz` the keeper runs does not build.
- `tests/fleet/a4_edges.rs::closed_merge_both_facts_fail_discovery`: the same helper with both facts set; each fact alone fails discovery in its own keeper (with `closed_merge_time_only_fails_discovery`), so a reader that ignores either fact fails one of them.
- `tests/fleet/a4_edges.rs::a7_scale_unbounded_transport_count`: the same 50 ms scale run on the real clock with the same two assertions (complete, 20 calls) as the keeper's fast form.
- `tests/fleet/a5_fleet.rs::its_help_says_what_it_reads_and_how_it_exits`: wording pin: it compared `fleet`'s usage, help and exit-code constants with literals. The keeper proves `openwiz --help` carries those lines in their places.
- `tests/fleet/a5_fleet.rs::no_checks_near_misses_leave_ticket_and_progress_unread`: the same 24 answers (`a4_no_checks.rs::failures`) through the same recognizer (`crates/adapters/github/src/process.rs`); that a failed checks read leaves `fleet`'s ticket and progress unread is `a5_fleet.rs::each_failed_read_is_recorded_and_every_value_it_reaches_names_it`.
- `tests/fleet/a6_reads.rs::the_fakes_allowlist_takes_exactly_the_one_new_form`: tests the fake `room-cli` only. The keeper asserts the adapter's exact calls, in order, on the wire.
- `tests/fleet/b4_archive.rs::the_fake_refuses_every_other_archive_shape`: tests the fake `room-cli` only. The keeper asserts the adapter's exact calls (`show`, one `archive`, `show`).
- `tests/fleet/a6_reads.rs::cloudroom_read_contracts_preserve_original_cases::the_new_invocation_is_exactly_its_approved_form`: source mirroring: an argv literal copied from `allowlist.rs`. The keeper asserts the same argv on the wire.
- `tests/fleet/b3_writes.rs::github_write_contracts_preserve_original_cases::every_write_and_its_read_back_is_exactly_a_form_written_out_here`: the keeper asserts `write.calls()` against its own hand-written list (`expected_calls`) for every write, and then the same calls on the wire.
