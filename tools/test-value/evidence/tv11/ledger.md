# TV11 (#813): the service group's ledger

Every test in `tests/service/` at the pull request's base, `fe405cf`, one
row each, in the form of `tools/test-value/README.md`: the `service` target
of `openwiz-tests` and the 15 `openwiz-service` test targets that read
`tests/service/`, plus the six tests there that run as unit tests of a
product crate's library (`install_engine_record_factory.rs` and
`install_engine_target.rs` in `openwiz-service`, `t7_transport.rs` in
`openwiz-adapter-github`).

- **Rows:** 325: kept 281, moved 15, deleted 29.
- **Kept** rows' Catches is the bug the test fails on, read from its
  assertions. A row whose test only runs as another test's child process
  says so: it asserts nothing by itself, and its parent catches the bug.
- **Deleted, with a keeper broken to check it** ([keepers.txt](keepers.txt)):
  the seven copies of the fixture-placement proofs (the helper is now the
  one shared `tests/support/place.rs`) and one in-process copy of the
  scheduled occupancy proof.
- **Deleted, no keeper to break:** the FIFO-harness self-tests, whose
  harness copies are gone, and one wording pin on a contract.
- **Moved:** `t4_scheduler.rs`, `t4_paths.rs` and `l5_watchdog.rs` to
  `crates/service/tests/`, unchanged, under the same target names.
  Where every other kept test lives, and why, is in [README.md](README.md).
